Upstream bugs found

simplifyRange("" on no match) — filed
When no version satisfies a range, simplifyRange returns "" — which parses as *, matching everything. A range that matched nothing silently becomes one that matches everything. Root cause and suggested patch in UPSTREAM_BUG.md.
gtr / ltr both return true — filed
For a prerelease excluded by the prerelease rule rather than by a range's bounds, both gtr() and ltr() report true — a version reported as simultaneously above and below the same range. Also in UPSTREAM_BUG.md.
