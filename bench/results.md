## Against the original

| | versions/sec |

| semver-rs | 11377569 |
| node-semver | 1420866 |
| ratio | 8.0x |

Only throughput is compared. A single-shot latency number for a
Node script is dominated by process startup and would say nothing
about the library itself.

## Method

Percentiles rather than a mean: parse latency is right-skewed, and
a mean hides the tail. Each measurement warms up for a tenth of its
iteration count before sampling. Peak RSS is read from
`/proc/self/status` (`VmHWM`).
